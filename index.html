Resumen

La extensión es local-first. La lista, el historial, los objetivos de precio, las preferencias y las gráficas permanecen en el perfil de Chrome del usuario. No operamos un servidor propio para recopilar esos datos.

Datos procesados

Al guardar un producto, la extensión puede conservar nombre, URL, imagen, precio, moneda, disponibilidad, historial observado, objetivo de precio y preferencias. La pestaña activa solo se lee después de una acción explícita del usuario.

Almacenamiento y eliminación

Los datos se guardan en chrome.storage.local. El usuario puede eliminarlos desde cada tarjeta, importar un respaldo JSON o limpiar/desinstalar la extensión.

Solicitudes a tiendas

El refresco manual solicita únicamente URLs de productos guardados, de forma secuencial y directamente desde el navegador. No hacemos rastreo masivo ni evadimos captchas. Las tiendas aplican sus propias políticas.

Sin analítica ni venta de datos

La v1 no usa analítica de terceros, publicidad, afiliados, correo, WhatsApp, modelos de lenguaje ni sincronización en la nube. No vendemos ni compartimos datos de navegación.
